## What it does

`main.ts` writes a single one-line office joke (under 200 characters) to `/output/entry.txt`:

> I replied-all asking everyone to stop replying-all, and now I have 47 unread emails about it.

## Run

```sh
node main.ts
```

The program is deterministic: every run writes the exact same bytes.
